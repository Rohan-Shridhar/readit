Get started in minutes.

Install readit in any Chromium browser. No store account needed.

Clone the repository

Needs git. No git? Use Download ZIP above and unzip it instead.

git clone https://github.com/Rohan-Shridhar/readit.git

Open the extensions page

Use Chrome, Edge, Brave or any Chromium browser. Paste this into the address bar (links to chrome:// pages are blocked, so copy it).

chrome://extensions

Turn on Developer mode

Flip the Developer mode switch in the top-right corner of the extensions page.

Load the extension

Click Load unpacked in the top-left, then pick the readit folder, the one that contains manifest.json.

Pin it and start reading

Pin the readit icon to your toolbar. Open it, click Select Text, drag across a passage, then press Space or reopen the popup and click Start Reading. Press Esc to stop.

readit can't run on chrome:// pages or the Chrome Web Store, and tabs that were already open need a reload after you install it.
